# 正負の数トレーニング

中学1年「正負の数」の4択ドリルアプリです。ビルド不要の静的サイト（HTML / CSS / JavaScriptのみ）なので、そのままVercelにデプロイできます。

## 機能

- 加法・減法・加減混合・乗法・除法・かっこを含む四則・絶対値・大小関係から、ランダムに4択問題を出題
- 「出題範囲を選ぶ」から、出したい種類だけにチェックを絞り込み可能（苦手分野の演習に）
- 出題数・正解数・正答率をリアルタイム表示、いつでもリセット可能
- 回答するとその場で正誤と正解を表示
- PWA対応：スマホのホーム画面に追加すると、アイコンから直接アプリのように起動できます（オフラインでも動作）

## スマホでホーム画面に追加する

デプロイ後のURLをスマホで開くと、画面下に追加を促すバナーが出ます。

- **iPhone（Safari）**: 共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**: バナーの「ホーム画面に追加」をタップ、またはメニューから「アプリをインストール」

追加後はアイコンをタップするだけで、ブラウザのアドレスバーなしの全画面アプリとして起動します。

## ローカルで確認する

ブラウザで `index.html` を直接開くだけで動作します。

簡易サーバーを使う場合：

```bash
npx serve .
```

## Vercelへのデプロイ

### 方法A：Vercel CLI

```bash
npm install -g vercel
cd seifukazu-quiz
vercel
```

質問にすべてデフォルトで答えればOKです（ビルドコマンド不要・出力ディレクトリはルートのまま）。本番反映は `vercel --prod`。

### 方法B：GitHubから取り込む

1. このフォルダの中身をGitHubリポジトリにプッシュ
2. [vercel.com](https://vercel.com) にログインし「Add New Project」
3. 対象のリポジトリを選択してインポート（Framework Presetは「Other」のままでOK、ビルド設定不要）
4. Deployをクリック

## ファイル構成

```
index.html    画面構造
style.css     デザイン（数直線モチーフ）
app.js        問題生成・採点ロジック・PWAインストール案内
manifest.json PWAマニフェスト（アプリ名・アイコン・配色）
sw.js         Service Worker（オフラインキャッシュ）
icons/        ホーム画面アイコン各種
favicon.ico   ブラウザタブ用アイコン
vercel.json   Vercel設定（最小構成）
```

## 出題内容や難易度を変えたいとき

`app.js` 内の各 `gen〇〇()` 関数で、数値の範囲（例：`randNonZero(-9, 9)`）を変更すると難易度を調整できます。新しい問題タイプを追加する場合は、`CATEGORIES` 配列に `{ id, label, gen }` を追加してください。
